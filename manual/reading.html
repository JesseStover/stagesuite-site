Reading riders

Bands send riders as PDFs, photos, spreadsheets or a few lines in an email. PatchWork Live reads them on the tablet into a plot you check.

A file

An act's window → Load their file… (or Options → Plot → Read an input list…). For a PDF, tick the pages to read — the input list, stage plot and backline pages are ticked for you. Read into a plot reads counts ("3 vocal mics"), lists in columns, numbers on the band's drawing, amp models and the backline page. Check what it read, then Make the plot.

Notes typed into an act

A rider pasted into an act's notes: the window's Their notes: Read into a plot. It reads sentences too — "Fiddle (mic on a short boom), bouzouki (DI), flute (mic)", "Bass: DI and a mic on the cab" (two inputs), "vocals: fiddle player and bouzouki player" (two vocals).

What it gets wrong

Clean lists read well; a page that mixes a drawing, a list and notes is read partly wrong. A read plot carries an orange not checked line: Compare shows their file beside the plot, Their file opens it.

With your own AI

With your own OpenAI or Claude key (⋮ → Settings → Your AI — a few cents a rider on your own account; the key stays on the tablet), Send to my AI → Read it now reads a rider with that AI, and opening a show (or Show ⋮ → Read every band with no plot) offers a checklist of every band on every day and stage that has a file or a typed rider and no plot — untick any, see the count and a rough cost, then Read. Without a key the ticked bands are read on the tablet, one check page each; a single act can still go to your own AI app.

Help → Getting your files in shows how to lay out gear lists, schedules, input lists and crew lists so they read cleanly.
