PatchWork Live on Windows

The same app on a Windows laptop or desktop, for the desk work — building the house, the master patch and plot, the running order and the bands' plots — beside the tablet you take to the stage. A show moves between the two as a file.

Installing

You get one file, PatchWorkLive-…-setup.exe. Double-click it and follow the steps. It needs no administrator rights: it installs for you alone, adds PatchWork Live to the Start menu and, if you tick it, an icon on the Desktop, and it can be removed like any other program. Your plots, shows and backups live in Documents\PatchWork Live and are never touched by installing, updating or removing the app. To update, run the newer set-up over the old one.

It needs Windows 10 or 11, 64-bit. The first time, Windows may say it protected your PC because the app is from an unknown publisher: choose More info → Run anyway.

The window opens full-screen and is called PatchWork Live.

Two views: the stage and the Show page

On a tablet you turn the tablet to move between the stage (sideways) and the Show page (upright). A computer window stays wide, so there are two buttons instead:

  • Show pages (top right of the stage) — the Show page, the same page the tablet shows upright.
  • Stage (top right of the Show page) — back to the stage plot.

Anywhere the app says "turn the tablet sideways", on Windows read it as "press Stage".

The house is on the Show page's House row: its Gear, Plot and Patch windows open the House window — the house's Gear list, its master plot or its master patch, each filling the window. Gear | Plot | Patch on its bar hops between the three and its back arrow returns to the show.

Mouse

  • Click is a tap, and drag moves things, exactly as on the tablet. A piece and its person move together.
  • Mouse wheel zooms the stage about the pointer; the arrows button on the right (Fit) puts the whole stage back.
  • Right-click does what pressing and holding does on the tablet, in an act's piece picker (a position's sheet, a piece's own choices, a moved box back).
  • SELECT (bottom right) is off at the start: a drag moves a person with their gear. Click it and clicking pieces picks several — a blue bar shows Rotate all · Duplicate all · Delete all; click it again to turn it off.

Keyboard

  • Delete (or Backspace) takes the selected pieces off the stage; use Ctrl+Z or the Undo button to bring them back. The "Deleted n items" line goes to Messages.
  • Ctrl+Z undoes, Ctrl+Y (or Ctrl+Shift+Z) redoes. They work on the stage; the Undo and Redo buttons in the top bar and on the toolbar always work too.
  • Ctrl + mouse wheel zooms the lists and pages.
  • Typing in a box (a name, a number) is never interrupted by these keys.

Messages

The Messages envelope beside Undo lists what the app said (newest first, a yellow number counts the new ones). There are no pop-up lines on Windows either.

Where your files are

Windows has no Download folder for the app the way an Android tablet does, so everything is kept in one folder, Documents\PatchWork Live, with the same sub-folders as on the tablet:

  • Plots — one file each, ending .stageplot. Plots kept in Documents\plots by an earlier version are moved in the first time you start.
  • Shows — the shows you save (⋮ → Show → Save show saves straight here; it asks for a name only when the show has none).
  • Patches — the master patches you save (.stagepatch).
  • Backups and PDFs — the automatic backup copy, and the PDFs you make.

The app's own working copy of the open show and your settings sit in its data folder under your user profile (AppData); you don't need to touch them. To move a show, use ⋮ → Show → More saving → Save show as zip: it writes the zip into Documents\PatchWork Live\Shows and says so — copy it from there. Save show as… asks only for a new name. To open one from anywhere: ⋮ → Show → Shows… → Other file… opens the Windows Open window, which lists shows (.stageshow), plots (.stageplot) and zips.

Moving a show between the PC and the tablet

  1. On the one you built it on: ⋮ → Show → More saving → Save show as zip. The zip holds the show, every act's plot and the schedule.
  2. Get the zip across (a USB cable, a cloud drive, an email to yourself).
  3. On the other: ⋮ → Show → Shows… → Other file… and pick the zip. On the tablet, the zip goes in the Download/PatchWork Live folder or you pick it with Other file….
Do a Save show as zip before you close a long session on the PC. It is also your backup.

What works the same

The Show page (days, stages, running order, changeovers), the House window (gear list, master plot and master patch), band plots and the plot editor, the schedule reader (from a file, pasted text, a PDF or a spreadsheet), the plot archive and Past bands, printing, and Help with this manual.

What isn't on Windows

  • Scanning a QR with the camera, and photo-based reading — use a file or pasted text.
  • The on-device rider reader (the one that reads a photo or PDF on the tablet); riders and schedules are read from files, text and spreadsheets.
  • Reading a schedule straight from a website's page, and the shake gesture for feedback — use Help → Send feedback.
  • Purchases, Google sign-in and push notices. The crew's phone app, 2ndRodeo, is for phones.

If something is wrong

  • The window opens off-screen or too big: press the Windows key + Up to maximise it, or drag it by the title bar.
  • A shortcut does nothing: click the stage once so the app has the keyboard, and check no text box is open.
  • Anything else: Help → Send feedback sends a note and a picture of the screen to the app's maker.
